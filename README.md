# Belajar.id Flask Website

A Flask-based frontend for the Belajar.id learning platform. The app includes:

- Home landing page with hero section, featured course, pipeline, and founder preview
- Courses catalog page with active course and upcoming pipeline
- Course detail page with curriculum, instructor profiles, and pricing sidebar
- Webinar registration page with form
- About page with founder story and values
- FAQ & contact page with accordion FAQ and contact form

## Run locally

1. Create a virtual environment:

```bash
python -m venv venv
```

2. Activate it:

```bash
venv\Scripts\activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the app:

```bash
python app.py
```

5. Open `http://127.0.0.1:5000`
