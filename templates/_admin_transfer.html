Transfer move the site's content to another server without pushing it through git

how it works
  1. Code (app.py, templates, css, js) goes to the new server through git. The repository holds no course, instructor, webinar or image data: .gitignore leaves it out.
  2. Content travels in one zip made here. Export on the old server, import on the new one.
  3. The admin password and the secret key are never included. The new server makes its own.
